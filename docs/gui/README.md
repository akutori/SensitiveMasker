# GUI画面・機能一覧

GUI(Tauri)が提供する画面と機能の一覧。ビルド・起動方法は[README.md](../../README.md#gui)を参照。

## 初回セットアップ

初回起動時のみ表示される。「始める」を押すと、鍵ファイルと暗号化データベースをOS標準のアプリデータフォルダに作成する(CLIの`masker init`と同じ処理)。2回目以降の起動では表示されない。

## メイン画面

起動直後に表示されるマスキング実行画面。

| 操作 | 内容 |
|---|---|
| プロファイル選択 | ドロップダウンでアクティブプロファイルを切り替える(切り替えは即座にDBへ反映される) |
| プロファイル一覧 | プロファイル管理画面を開く |
| インポート | エクスポート済みファイル(`.smx`)からのインポートダイアログを開く |
| 再読み込み | プロファイル一覧・タグ一覧を再取得する(他画面・トレイ・別プロセス(CLI等)での変更を反映する) |
| 新規作成 / プロファイルを編集 | ルール編集画面を開く(プロファイルが1件も無い場合、編集は無効) |
| 入力テキスト | Monaco Editorで編集(Ctrl+Fで検索、Ctrl+Hで置換) |
| ファイルから | 選択したファイルをUTF-8として読み込み、「入力テキスト欄に読み込む」(入力欄に既存内容がある場合は上書き確認)または「直接マスクして別ファイルに保存」を選べる。UTF-8として解釈できないバイト列があった場合は置き換えて読み込みを継続し、警告を表示する(停止はしない) |
| マスク実行 | アクティブプロファイルの全有効ルールを適用し、出力欄に結果を表示する(プロファイル未選択時は無効) |
| クリア | 入力・出力欄と、連番モードの対応表(マッピング)を破棄する |
| 出力テキスト | 読み取り専用。「ファイルに保存」または「クリップボードにコピー」で書き出す |

連番モード(`sequential`)の採番はプロファイルごとに保持され、同じ値は同じダミー値に置き換えられる(「クリア」でリセットするまで、同一セッション内で一貫する)。

「ファイルから」の「直接マスクして別ファイルに保存」は、保存前にルールごとのマッチ件数を確認する画面を経由する(マスク後の内容そのものはこの画面には表示されない)。マッチ件数が0件のルールがある場合は注意書きが表示される。

## プロファイル管理画面

| 操作 | 内容 |
|---|---|
| 検索 | プロファイル名の部分一致で絞り込む |
| 並び替え | 更新日時等での並び替え |
| ★お気に入りのみ | お気に入り登録済みのプロファイルのみ表示する |
| タグ絞り込み | 選択した全てのタグを持つプロファイルのみ表示する(AND条件) |
| + 新規プロファイル / テンプレートから作成 | ルール編集画面を開く(テンプレートは組み込みのルール例からの作成) |
| タグを管理 | タグの作成・改名・削除(プロファイルへの割り当てとは別画面) |
| 全体エクスポート / インポート | 下記「エクスポート/インポート」参照 |
| envインポート | 下記「envインポート」参照 |

各プロファイル行の操作:

- **編集**: ルール編集画面を開く
- **タグ**: そのプロファイルへのタグ割り当てを変更する
- **複製**: 名前を指定して複製する(同名がある場合はエラー)
- **エクスポート**: そのプロファイル単体をエクスポートする
- **削除**: アクティブなプロファイルは削除できない(先に他のプロファイルへ切り替える必要がある)
- **★**: お気に入りの切り替え
- 行のクリック: そのプロファイルをアクティブにする(編集は「編集」から)

ルールが1件も無い、または全ルールが無効化されているプロファイルには警告アイコンが表示される(マスクされないまま気付かず使われることを防ぐため)。

## ルール編集画面

| 操作 | 内容 |
|---|---|
| プロファイル名・説明・タグ | プロファイルのメタ情報 |
| ルール一覧 | ドラッグ&ドロップで並べ替え、チェックボックスで個別に有効/無効を切り替え |
| + ルールを追加 | 種別(リテラル/正規表現)・モード(固定/連番)・パターン等を入力するダイアログを開く。テンプレートからの入力補完も可能 |
| 編集 / 複製 / 削除 | 各ルールに対する操作(同名ルールは作成できない) |
| サンプルテキスト / マスク結果 | 現在編集中の全ルールをリアルタイムに適用したプレビュー(保存前に確認できる) |
| 保存 / キャンセル | キャンセル時、未保存の変更があれば破棄確認ダイアログを表示する |

## エクスポート/インポート

プロファイルをファイル(`.smx`、[age](https://age-encryption.org/)形式で暗号化)として書き出し・取り込みする機能。コマンドの詳細は[masker export](../cli/README.md#masker-export---profile-nameoutput-file) / [masker import](../cli/README.md#masker-import---input-file---yes)と共通(GUIは同じ`profile-store`の処理を呼び出す)。

**エクスポート**: パスフレーズはGUI側で自動生成される(CLIのような手入力ではない)。「表示」(目のアイコン)で内容確認、「コピー」でクリップボードへコピーできる。コピーの30秒後に自動クリアを試みる(通知と注意文にも、この秒数を表示する)が、Windows以外の環境ではクリップボード履歴に残る場合がある(確実に消すには手動でクリアする必要がある)。コピーの書き込みに失敗した場合も、書き込みの途中で値が残らないよう、同じ値が残っていればクリアを試みる。

エクスポートに成功しても画面は閉じず、パスフレーズを表示(既定は伏せ字)・コピーできる状態のまま、「閉じる」を待つ。この画面を閉じるとパスフレーズは破棄され、二度と表示できない。成功後は「再生成」と「エクスポート」を出さず(書き出したファイルと画面のパスフレーズが食い違うため)、Escapeや背景を押す操作では閉じない(「閉じる」と×だけで閉じる)。エクスポート実行中はボタンを全て無効にし、閉じる操作(×・Escape・背景を押す)も受け付けず、フォーカスは画面の内側に留める。実行中・成功後は、履歴の移動(マウスの戻るボタンなど)でこの画面ごと消えることも止める。保存先の選択を取り消した場合と書き出しに失敗した場合は、編集中の画面へ戻る。コピー/クリアの処理中は、コピーと再生成を無効にする。エクスポートの完了は、画面の通知に加えて、スクリーンリーダー向けの読み上げの領域にも入る(実機のスクリーンリーダーでの読み上げは未確認)。

**インポート**: ファイル選択・パスフレーズ入力の後、取り込まれるプロファイル・ルールの内容(名前・種別・モード・パターン・有効/無効)を一覧表示する確認画面を経てから実行する。全体エクスポートのファイルを取り込む場合、名前が重複するプロファイルは自動的にリネームされる(例: `SIP監視用` → `SIP監視用 (インポート)`)。

パスフレーズの入力欄は伏せ字から始まり、「表示」(目のアイコン)で入力内容を確認できる(手入力の打ち間違いを目で確かめるため)。マウスで押した後も続けて入力でき、画面を開き直すたびに伏せ字へ戻る。

復号(数百ミリ秒〜数秒)の間は、OKを押せず、入力も変えられず、その理由を「復号しています…」と示す(フォーカスは入力欄に置く。閉じることはできる)。復号している間に閉じた場合は、同じファイルを開き直した場合も含め、復号が終わっても確認画面へ進まず、復号済みの内容は破棄される。開き直した画面は、古い復号が終わるまで、入力できない状態で待つ。画面を離れた場合も、復号済みの内容は破棄される。

復号済みの内容(Rust側の保留)は、復号のたびに払い出す識別子で結び付ける。確認画面の確定・取り消し・離脱は、その確認画面を持つ画面(メイン画面・プロファイル管理画面)が所有する識別子の保留だけを対象にし、他の画面が始めた復号の保留には作用しない。そのため、復号している最中に画面を離れ、別の画面で別のファイルの復号を始めても(古い復号の結果が、後から届いても)、新しい画面の確認画面に出た内容と、確定される内容は一致する。保持できる保留は同時に4件までで、超えると最も古いものを捨てる(捨てられた保留の確定は「確認待ちのインポートがありません」で失敗する)。確認画面を開いたままWebViewが再読み込みされた場合(復号している最中の再読み込みを含む)は、識別子を持つ画面が無くなるため、ページの読み込みが始まった時点で、全ての保留が破棄され、復号している最中の結果も保留されない。ページ内の画面遷移は、ページの読み込みを起こさないため、この破棄は起きない(WebView2の場合。他のウェブビューでも同じとは限らない)。

貼り付けなどで前後に空白(全角スペースを含む)や、ゼロ幅文字(U+200B・U+200C・U+200D・U+2060)・BOM(U+FEFF)が混ざり、入力どおりでは復号できなかった場合に限り、それらを取り除いて1度だけ再試行する。入力どおりで復号できる場合は再試行しない(コマンドラインの`masker import`も同じ)。再試行で復号できたときは、確認画面の説明に、取り除いたことを示す一文が加わる(コマンドラインでは、標準エラー出力に、同じ趣旨が出る)。

## envインポート

`.env`ファイルのKEY=VALUEをそのまま取り込み、値をリテラル一致・固定値で置換するルールとして持つ新規プロファイルを作成する機能。正規表現ではなく実際の値そのものと一致させるため、値が変わらない限り確実に検出できる。

プロファイル管理画面の「envインポート」からファイルを選択すると、取り込み対象の選択画面が開く。値が短すぎるもの(4文字未満)、`PORT`・`DEBUG`等の非機微な運用系キー、引用符が閉じておらず複数行にまたがっている疑いのある値(PEM形式の秘密鍵等、1行ずつの解析では正しく取り込めないため)は既定で選択から外れるが、これはあくまで初期選択のヒントであり、最終的な取り込み対象はここで選び直せる。値は録画・配信時の映り込みを防ぐため既定で非表示(●)にしており、「値を表示」で一括切り替えできる。選択後、プロファイル名を入力すると作成される。

## 常駐トレイ

メイン画面を閉じる(×ボタン)とアプリは終了せずトレイに格納される。終了はトレイメニューの「終了」からのみ行う。

| メニュー項目 | 内容 |
|---|---|
| 開く | メインウィンドウを復帰させる(左クリックでも同じ動作) |
| クリップボードをマスク | アクティブプロファイルでクリップボードの内容をマスクし、そのまま書き戻す(アクティブプロファイル未設定の場合は無効) |
| プロファイル切り替え | サブメニューから直接アクティブプロファイルを切り替える |
| 自動起動 | OS起動時にアプリを自動起動するかどうかのトグル |
| 終了 | アプリを終了する |
